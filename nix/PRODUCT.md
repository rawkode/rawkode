# Desktop shell

## Register

product

## Users

Rawkode, using Niri across Linux desktop and laptop displays.

## Product Purpose

Provide a compact bar, notifications, and Wi-Fi/Bluetooth controls while retaining
the existing launcher, compositor, and lock/idle workflow.

## Brand Personality

Compact, familiar, restrained. Preserve the existing Monaspace typography and
Stylix theme, alongside Dux Shell.

## Anti-references

Avoid a desktop redesign, decorative animation, and unnecessarily spacious controls.

## Design Principles

- Preserve familiar shortcuts and monitor behavior.
- Show connection state and actionable failures.
- Keep desktop services independently recoverable.
- Use existing theme values rather than a second palette.

## Accessibility & Inclusion

Use labeled standard controls, keyboard focus and Escape dismissal, plain-text
notification bodies, scalable layout, and no required animation.
