# Fieldnotes for the web

## Register

product

## Users

The same person writing in the native Fieldnotes macOS spike, now opening the same note in a browser. They switch between prose, code, diagrams, sketches, and reference links while thinking and writing.

## Product Purpose

One continuous rich-text document, with native-style selection and keyboard flow, portable note files, and editable inline components. Success is a note that survives native to web to native editing without losing content.

## Brand Personality

Quiet, precise, familiar. Mirror Fieldnotes; borrow Notion's keyboard-first block authoring, not its workspace dashboard.

## Anti-references

No dashboard, marketing chrome, stacked independent text fields, decorative card grid, or feature wall. No unsupported promises of live sync.

## Design Principles

- The document is the primary surface.
- Shared content remains independent of its editor projection.
- Commands should be available from the keyboard and visible controls.
- Preserve source and drafts when an operation fails.
- Distinguish saved locally, exported, and not saved.

## Accessibility & Inclusion

Keyboard operation, visible focus, screen-reader labels, adequate contrast, and reduced-motion support. Standard accessible controls; do not rely on color alone.
